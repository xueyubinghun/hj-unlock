⚡ 安装脚本 v4.5.0
点上面按钮后，脚本管理器会弹出安装页。
如果没反应，长按按钮 → 复制链接 → 到脚本管理器里「从 URL 导入」。

首次使用

  1. 安装后在脚本管理器里确认已启用
  2. 打开海角站点（任意镜像域名都行）
  3. 弹出激活码 → 输入管理员给你的码
  4. 右下角出现「希」字光球 → 点开 → 播放

使用说明

  • ▶ 播放 — 解密并播放当前帖子/短视频
  • ⬇ 下载 — 完整下载到本地（12 并发）
  • ⤢ 放大 — 播放器全屏
  • ⚙ 凭证 — 填自己的已购帖子 id
  • 长按播放画面左右两侧 → 2 倍速
  • 长视频会先预缓存约 8%，期间可以切页浏览
  • 光球可以拖动，位置会记住
